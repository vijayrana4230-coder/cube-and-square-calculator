
<H1 align="center">Cube & Square Calculator</H1>
<p>A simple web-based<b> Cube and Square Calculator</b> built using <b>HTML, CSS, and JavaScript</b>. This project allows users to enter a number and instantly calculate its Square and Cube with a clean and user-friendly interface.</p>
<hr>
<h2>Features</h2>
<ul>
<li>✅ Calculate the Square of a number</li>
<li>✅ Calculate the Cube of a number</li>
<li>✅ Clear input and result with one click</li>
<li>✅ Responsive and simple UI</li>
<li>✅ Beginner-friendly JavaScript project</li>
</ul>
<hr>
<h2>Technologies Used</h2>
<ul>
<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript (DOM Manipulation)</li>
</ul>

</pre>

<h2>How It Works</h2>
<ol>
<li>Enter a number in the input box.</li>
<li>Click<b> Square</b> to calculate the square.</li>
<li>Click<b> Cube</b> to calculate the cube.</li>
<li>Click<b> Clear</b> to reset the input and output.</li>
</ol>
